4. Internal Control
Plane (ICP)

The Internal Control Plane provides access to the PHY configuration registers. This interface is separate from the high-speed data path.

4.1 Register access

The ICP interface supports register read and write operations through a dedicated address and control bus. Access is performed using the address signal and the corresponding read or write enable.

SignalDirectionDescription
icp_addrInputRegister address
icp_rd_enInputRead enable
icp_wr_enInputWrite enable

4.2 Address space

The address space is used to select the target configuration register. Refer to the corresponding register definition for field-level information.
